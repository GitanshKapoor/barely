# Barely 🧪

> Barely is an open-source AI agent for end-to-end web testing.

Write what to test in plain English. Barely's AI agent does the rest — 
navigates your app, takes screenshots, catches bugs, generates PDF reports, 
and files Jira tickets. No Selenium. No Playwright scripts. No flaky tests.

## Why Barely?
Manual testing is slow. Playwright/Selenium scripts break on every UI change. 
Barely brings declarative, goal-based testing to your CI/CD pipeline using AI.

## Quick Start (Coming Soon)
```bash
pip install barely
barely init
barely run --url https://staging.myapp.com --goal .barely/goals/login.md
```
